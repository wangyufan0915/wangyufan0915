## 代表项目

### 📬 学校通知汇总器
`JavaScript · Node.js`

大学的通知都发在微信 / QQ / 钉钉里，而这三者都没有可用的消息接口。通知以"复制粘贴的文本"形式出现，然后就找不到了。

这个工具把原始导出文本变成一份每日 Markdown 日报和一份可导入手机的截止提醒 `.ics`：

- **规则式解析**三种平台的导出格式（时间戳、发送者、群名头、转发块）
- **中文截止时间抽取**：`9月25日前`、`本周三`、`今晚22:00`、`截止时间 9月28日 24:00`
- **跨平台去重**：用字符二元组 Jaccard 相似度合并"同一通知被转发到三个 App"的情况
- **群白名单过滤**：支持包含 / 前缀`*` / `/正则/`，并能自动扫描候选群名
- **输出**：`YYYY-MM-DD.md` 日报、`YYYY-MM-DD.ics` 提醒、`notices.json` 历史库

> 设计取舍：我**没有**做消息自动抓取。读取微信/QQ 本地消息库需要逆向协议，客户端一升级就失效，还可能封号。工具保持诚实——人花几秒导出文本，剩下全交给机器。

### 🗓️ 课表转日历
`Python`

约 100 行脚本：把课表数据（课程、地点、教师、周次、星期、节次）展开成标准 `.ics` 文件。14 个节次全部映射到真实时钟时间，按教学周逐周展开，一次导入即可覆盖整个学期。起因是官方课表只有 PDF 表格。
